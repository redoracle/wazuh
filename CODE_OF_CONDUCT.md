# Code of conduct

## Commitment

Contributors, maintainers, and reviewers are expected to be professional,
respectful, constructive and inclusive in issues, discussions, code reviews
and other project spaces. Technical disagreement is welcome; personal attacks,
harassment, discrimination, intimidation, threats and publication of another
person's private information are not.

## Review and collaboration

- Address ideas and code, not personal characteristics.
- Provide reproducible evidence for claims about security or compatibility.
- Respect differing levels of familiarity with the legacy infrastructure.
- Keep private production data, credentials, vulnerability details and host
  identifiers out of public discussions.
- Accept proportionate moderation decisions intended to preserve a safe,
  constructive working environment.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainer through an
appropriate non-public channel. Avoid disclosing the complainant's identity or
private details in public issues. Maintainers may edit, hide, close or lock
harmful discussions and restrict access for serious or repeated violations.

For software vulnerabilities, use the separate
[security reporting policy](SECURITY.md), not a conduct complaint or public bug
report.
