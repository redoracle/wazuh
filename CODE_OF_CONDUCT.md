# Code of conduct

Contributors and maintainers are expected to be respectful, inclusive, technically constructive and privacy-conscious. Harassment, discriminatory behavior, personal attacks, the publication of private credentials and deliberate disruption are not acceptable.

Report conduct concerns privately to the repository maintainers via an appropriate trusted channel. Maintainers may moderate discussions, remove harmful content and restrict accounts when necessary. Security vulnerabilities follow the separate [Security policy](SECURITY.md).
