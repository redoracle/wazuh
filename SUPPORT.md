# Support

This is an independently maintained Compose integration, not the official Wazuh support channel.

For a configuration or documentation defect, open a GitHub issue with the pinned release, host OS/architecture, Docker Compose version, sanitized logs and a clear reproduction. For potential security disclosures, **do not use public issues**: see [Security](SECURITY.md).

For Wazuh product behavior, agent integrations, release compatibility and container troubleshooting, use the official [Wazuh documentation](https://documentation.wazuh.com/current/) and [wazuh/wazuh-docker](https://github.com/wazuh/wazuh-docker) project. Production support SLAs, disaster recovery and custom migration services are not provided by this repository.
